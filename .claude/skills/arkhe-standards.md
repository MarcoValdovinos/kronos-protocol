# Habilidades y Estandares para Asistentes de IA

Si eres una IA ayudando en el repositorio ARKHE ZERO, sigue estas reglas:

1. Soberania 51/49: Ningun codigo generado por ti puede saltarse la validacion humana.
2. Sello Obligatorio: Todo archivo .py o .js nuevo debe iniciar con el sello 51/49.
3. Ubicacion de Documentacion:
   - No agregues archivos .md en la raiz a menos que sea el README.md.
   - Si creas un tutorial, ve a docs/guides/.
   - Si creas una guia tecnica de CI/CD, ve a development/docs/.
4. No toques las Llaves: Ignora siempre la carpeta 07-LLAVES/ y archivos .env.
